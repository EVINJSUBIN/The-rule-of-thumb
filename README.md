## What Is This?

We will build an offline documentation tool where we can look at realtime docs. We can monitor our Hack Club usage etc and code completely kinda offline. This integrates into all LLMs as a specific skill or MCP, monitors the AI usage and caps it out for the user, warns them, and also logs this clearly on the project they're working on. This helps the user to actually code offline and learn by themselves.

---

## Features

1. **Offline Docs** — Offline documentation right out of the box
2. **AI Based Planning and Guiding, No Coding** — A sarcastic AI that forces you to study the architectures, the principles, the whole logic behind it and then code by yourself. It does not code for you.
3. **Error Analyzing** — Analyze your errors and learn from them
4. **Web-Based StackOverflow Kinda Community** — A community to help each other out
5. **UI** — We need to work on the UI side etc, we will eventually reach at that point one day
6. **Reliable Code Time Tracker** — Realtime, like Hacktime is tracking but it has glitches showing it in real time so we need to fix or make something else to fix it in our product. Works completely offline across multiple projects.
